Privacy policy

This policy describes how Personal Secretary, a personal self-hosted assistant, handles Google user data when you connect a Google account.

Google data accessed

  • Gmail data, so Secretary can read, search, and summarize mail, and send mail only when you explicitly ask and approve.
  • Google Calendar data, so Secretary can read calendars and events, and create events only when you explicitly ask and approve.
  • Google Drive metadata and content. Secretary reads file metadata and, when you explicitly request it, fetches or exports file content for Secretary context.

Purposes

That data is used for user-requested productivity: search and context, synchronization, and task, calendar, and email workflows.

Storage

Secretary may store imported source data in its own database so those features keep working. Google OAuth credentials and tokens are stored encrypted at rest by Secretary.

Sharing

Google user data is not sold and is not used for advertising.

When AI features are enabled and configured, Secretary may send only the relevant data needed for the requested feature to the configured AI provider.

Revoking access

You can revoke Google access in your Google Account. Revocation stops future access. Data already imported into Secretary may remain until you remove it from Secretary or its storage.

Security

Secretary restricts access to the server and stores Google tokens encrypted at rest. This does not promise that unauthorized access is impossible.

Contact

For privacy questions, use the support contact shown on the Google OAuth consent screen.
