Personal Secretary

Personal Secretary is a personal, self-hosted productivity assistant. You use it on your own Secretary server. It is not a public multi-tenant service.

What it does

At a high level, Personal Secretary brings together:

  • a unified inbox and conversation context;
  • search across the material you have imported;
  • tasks;
  • calendar and email assistance;
  • files;
  • optional AI-assisted features when you configure them.

Why Google access is requested

If you connect a Google account, Personal Secretary requests access only for the Google features you choose to use:

  • Gmail. Read, search, and summarize mail. Send mail only when you explicitly ask and approve that action.
  • Google Calendar. Read your calendar and events. Create calendar events only when you explicitly ask and approve that action.
  • Google Drive. Read file metadata and, when you explicitly request it, fetch or export file content so Secretary can use it as context.
